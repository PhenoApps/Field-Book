## 术语一致性抽查

以下术语全应用范围内应保持一致：

| English | 中文 | 抽查位置 |
|---------|------|----------|
| trait | 性状 | 性状列表、性状详情、性状参数 |
| plot | 小区 | 田块预览、田间导航 |
| field | 田块 | 主界面、导入、BrAPI导入 |
| study | 试验 | BrAPI导入、观测值元数据 |
| entry | 条目 | 采集界面、田块详情 |
| observation | 观测值 | 同步、统计、采集 |
| germplasm | 种质 | BrAPI导入进度 |
| GeoNav | 田间导航 | 设置、采集、教程 |
| cancel | 取消 | 各对话框 |
| save/delete | 保存/删除 | 各界面操作 |
| NA | 缺失 | 采集界面 |
